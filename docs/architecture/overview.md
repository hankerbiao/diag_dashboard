## 设计原则

### 全链路异步

后端全栈使用 `async/await` — Motor 驱动 MongoDB、httpx 驱动 HTTP 调用、asyncio 驱动定时调度。无同步阻塞操作。

### 单一数据源

厂区配置统一由 `configs/factories.yaml` 管理，后端 `factory_config.py` 和独立同步脚本均从此文件读取。

### 可选依赖

RAGFlow 和 LLM API 均为可选配置。未配置时，知识库功能不可用，诊断回退为 mock 模式。

### 缓存优先

看板数据每小时预计算写入 MongoDB 快照，诊断结果缓存到 `diagnosis_cache`，避免重复计算。
