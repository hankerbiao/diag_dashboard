# Plan: 登录页 AI 主题重设计

## 现状

登录页 `LoginPage.tsx` 是居中卡片布局：Logo + "WeaveEye 智能诊断系统" + 邮箱/密码表单 + 登录/注册切换。视觉简洁但缺少品牌辨识度。

## 需求理解

将登录页从"纯表单卡片"升级为"品牌展示 + 登录入口"的双栏布局，左侧展示 AI 视觉元素和系统数据，右侧保留表单功能。

---

### AI 视觉元素

**1. Canvas 粒子动画背景 (`ParticleBackground.tsx`)**
- 全屏 Canvas 组件，绘制 ~80 个粒子
- 粒子间距离 < 阈值时绘制连接线（模拟神经网络）
- 粒子缓慢漂移，鼠标附近粒子轻微吸引
- 配色跟随主题 (light: blue/purple, dark: cyan/magenta)

**2. 品牌展示区 (左侧)**
- Logo + "WeaveEye" 渐变标题
- 打字机动画标语：每 3 秒切换显示一条 AI 诊断相关文案
  - "智能分析每一条异常日志..."
  - "基于知识图谱的深度推理..."
  - "覆盖 10+ 厂区实时数据同步..."
  - "毫秒级 SN 诊断查询..."

**3. 数据统计卡片 (3 张)**
- 展示已同步服务器数量、案例库条目数、AI 诊断准确率
- 数字使用 `count-up` 动画效果（从 0 滚动到目标数字）
- 每张卡片带一个小图标（Server, Database, Target）
- 数据初期可用静态展示数据，后续可通过 `/api/health` 扩展接口接入真实数据

### 右侧表单卡片

- Glassmorphism 风格（半透明背景 + backdrop-blur + 细边框）
- 保留现有功能（邮箱/密码/记住密码/登录注册切换）
- 增加:
  - 输入框聚焦时发光边框动画
  - 登录按钮 hover 时渐变流动效果
  - 错误/成功提示的滑入动画

## 实施阶段

### Phase 1: 粒子动画背景 (约 1.5h)

**新建 `src/components/auth/ParticleBackground.tsx`**
- Canvas 全屏背景组件
- 粒子系统：位置、速度、半径、透明度
- 连接线绘制：距离阈值内粒子间连线，透明度随距离递减
- 鼠标交互：鼠标附近粒子轻微吸引效果
- Resize 响应
- `requestAnimationFrame` 循环
- 性能优化：粒子数控制在 ~80 个，使用 `useRef` 避免重渲染

### Phase 2: 品牌展示区 + 数据卡片 (约 1.5h)

**新建 `src/components/auth/BrandPanel.tsx`**
- Logo 区：Bot 图标 + 渐变标题
- 打字机标语动画（`useEffect` + `setInterval` + CSS typing cursor）
- 3 张数据统计卡片（静态展示数据，数字滚动动画）
- 响应式：移动端时品牌区高度折叠或隐藏

**新建 `src/components/auth/StatCard.tsx`**
- 接收 `icon`, `label`, `value`, `unit` props
- 数字 count-up 动画（`useEffect` + `requestAnimationFrame` 或 `setInterval`）
- 毛玻璃卡片样式

### Phase 3: 登录表单升级 (约 1h)

**修改 `LoginPage.tsx`**
- 改为双栏 flex 布局
- 左侧 `<BrandPanel />`
- 右侧表单卡片：添加 glassmorphism 样式
- 输入框聚焦发光效果（CSS `:focus-within` + `box-shadow`）
- 添加过渡动画（framer-motion 的 `AnimatePresence` 已可用，使用 CSS transition 更轻量）
- 移动端响应式：< 768px 时上下布局，品牌区简化

**保留不变**：
- `handleSubmit` 逻辑
- `remember` 自动填充逻辑
- 错误/成功提示逻辑

### Phase 4: 移动端适配 (约 0.5h)
- `md:` 断点：≥768px 双栏，<768px 单栏（品牌区在上）
- 小屏时品牌区仅显示 Logo + 标题 + 标语，隐藏数据卡片
- 粒子动画在小屏降低粒子密度

## 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| Canvas 动画在低性能设备不流畅 | LOW | 粒子数控制 ~80 个，可降级为静态渐变背景 |
| 统计数字目前无真实数据来源 | MEDIUM | 先用静态展示数据，后续可从 `/api/health` 或统计接口接入 |
| 打字机动画中文渲染闪烁 | LOW | 使用 `ch` 单位 + `overflow: hidden` 避免宽度跳动 |
| Glassmorphism 在不同浏览器一致性 | LOW | 使用 Tailwind `backdrop-blur` + 渐进增强，不支持时降级为实色背景 |

## 估时：~4.5h
