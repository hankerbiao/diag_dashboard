# WeaveEye Backend 文档

FastAPI 后端开发与运维文档（VitePress）。

## 命令

```bash
npm install
npm run docs:dev      # 开发服务器
npm run docs:build    # 构建静态站
npm run docs:preview  # 预览构建结果
```

## 目录

- `guide/` — 入门与配置
- `architecture/` — 架构与生命周期
- `core/` — 基础设施模块
- `routers/` — HTTP API 层
- `services/` — 业务服务层
- `workflows/` — 端到端业务流程
- `database/` — MongoDB
- `deployment/` — 部署
- `operations/` — 运维排障
- `api/` — API 说明（详细 schema 见 `/docs` Swagger）

项目根目录另有全栈文档：`../../docs/`。
